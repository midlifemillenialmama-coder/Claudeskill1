# Weekly Brief

A Claude Cowork plugin with one skill. It reads your calendar, inbox, and Drive and writes a one-page brief: what needs a reply, what you are waiting on, and what the week looks like. It only reads. It never sends or changes anything.

## Needs
Google Calendar, Gmail, and Google Drive connectors (any subset works).

## Use
Ask: "Give me my weekly brief" or "Plan my week".

## Tune
Edit `skills/weekly-brief/references/preferences.md` to set priority people, ignored senders, and working hours.

## Install
Zip the `weekly-brief` folder as `weekly-brief.plugin` and upload it in Cowork, or add this repo as a marketplace in Claude Code.
